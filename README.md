
# Number Guessing Game

A very simple number guessing game built on python using the random library.

## Installation/Use

To deploy this project please download the source code as a .zip file. You can do this by clicking the green "code" button at the top of the github repository and then download as .zip.

Once downloaded you must extract the .zip, next open your terminal and navigate to the extracted folder with the cmd "/cd <The_Folders_Directory>" if on windows. Use "cd <The_Folders_Directory>" if on Mac.
 
Once in the correct directory you can use the main python command:

"python numguessgame.py" to run the program.   Upon running the program the termial will output:

"Welcome to the Number Guessing Game!
I'm thinking of a number between 1 and 100.
Enter your guess: " 

Here you can go ahead and start to enter your guesses.
 The game will let you know if your guess is too high, too low, or correct. Have fun and guess on!
